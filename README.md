## The short version

I'm a fullstack developer with a Data Analyst / Informatics Engineering background — which is a fancy way of saying I've spent equal time building interfaces *and* reading the numbers those interfaces produce. That combination is why I don't just ship a landing page; I want to know what it does to leads, traffic, and conversion once it's live.

Since 2020 I've moved through radio broadcasting, freelance web builds, agency contract work, and most recently mobile + AI-assisted frontend at a game studio. Six roles, one thread running through all of them: take a system that's a little rough, make it reliable, make it fast, and make the data behind it make sense.

## The journey

<details open>
<summary><b>🎮 PT Kalanara Group Indonesia — Fullstack Programmer (Contract)</b> · Mar 2026 – Jul 2026</summary>
<br />

The most recent chapter, and the busiest — four workstreams running in parallel on a games/entertainment product.

**📱 Mobile (React Native, Android & iOS)**
- Built and maintained multiple React Native apps across both platforms, including a face-recognition check-in/check-out attendance feature.
- Redesigned UI on three apps based on updated UI/UX specs, and cross-checked every mobile-to-web API integration to catch incorrect or dummy endpoints before they shipped.
- Shipped Android builds via Gradle (`assembleRelease` / `bundleRelease`) and managed iOS beta distribution through TestFlight, plus Play Console rollout on the Android side.

**🌐 Web & QA (Next.js, Three.js)**
- Rebuilt a promotional game website with Three.js for 3D visuals and Animate.js for scroll animation.
- Ran QA as a mix of automated E2E (Playwright + Cypress) and manual test cases across functional flows, edge cases, and cross-browser checks.

**🤖 AI-assisted frontend (with Claude)**
- Took an app from functional-but-basic UI to something sharper — researched modern component/animation libraries (Framer Motion, 21st.dev, Aceternity UI, Magic UI, Motion Primitives, shadcn/ui), then used Claude to work out the correct implementation path for each pattern inside the existing codebase.
- Applied that to [LoveCoupleGames](https://lovecouplegames.com/), an interactive web game — implementing complex UI/animation without regressing Largest Contentful Paint (LCP).
- Net effect: a lot less trial-and-error when adopting new patterns, since the research-first approach meant I understood a component before touching code.

**💳 In-app purchases (React Native Expo)**
- Diagnosed and fixed IAP integration issues on a separate Expo project — product entitlements, transaction validation, the works.
- QA'd purchase flows with Playwright/Cypress automation plus manual edge-case verification before release.
